## Cómo está construido
- **Semántica:** este codigo esta construido con los siguientes elementos: <!DOCTYPE html> nos sirve para indicar al navegador que el documento utiliza una version moderna de html, <html lang="es"> Indica que el idioma principal del contenido es el español, <head> es la informacion tecnica de mi pagina codificacion, titulo, y el enlace de estilo, <title> para el titulo oficial de la pestaña del navegador, <header> esta nos sirve para la cabezera, <h> encabezados con jerarquia de los titulos, <nav> define el bloque dedicado a los enlaces de navegacion, <main> es la estructura para el contenido en bloque, <section> agrupa contenidos tematicos relacionados como el catalogo, pedidos, horarios, <article> contenido independiente por ejemplo cada producto, <table> ordanizador de datos en filas y columnas,  <caption> proporciona un titulo o descripcion a la tabla, <img> inserta imagenes a la pagina web, <legend> Este propòrciona un titulo o etiqueta descriptiva, <form> fefine el formulario interativo de la pagina, <div> lo agrege para las redes soliciales en contactos para que entre directo al link de la red social como facebook y Whatsapp, target="_blank" sirve para abrir los enlaces puestas en la pagina evitando que salga de la pagina,<address> indica que el texto correspondiente a una informacion de contacto y un telefono. 
- **Layout:** LEXBOX: una dimensión para distribuir los elementos de menu y aliniar el contenido de la pagina, GRID: dos dimensiones, sirve para mostrar targetas de productos en filas y columnas 
- **Diseño:** [paleta y tipografía, y por qué las elegiste] utilze una paleta de colores unisex color azul jugando con los colores para ver que quede bien viendo cada funcion del CUSTOM PROPERTIES y a su lado jugue con los colores en si, el tipo de letra que use fue Times New Roman para un tipo por su letra un poco fina y bien visualmente.
