# TIENDA DE ROPA "ANGELICA BOUTIQUE" — LABORATORIO 2 Y 3

**Estudiante:** Miguel Angel Kato Ortiz | **Cliente:** Angelica Ortiz Choquehuanca | **Ciudad:** La Paz, Bolivia

**Laboratorio 2:** Se desarrolló la tienda web de Angelica Boutique utilizando HTML5 semántico y diseño adaptable con CSS Grid, Flexbox y modo oscuro. Con JavaScript se creó el catálogo dinámico de prendas (poleras de algodón, pantalones y chompas de lana, y pijamas), incorporando un buscador en tiempo real, filtros por categoría, ordenamiento de productos y validación del formulario de pedidos.

**Laboratorio 3:** Se añadieron animaciones interactivas con jQuery (menú móvil, preguntas frecuentes y avisos), consulta de stock en tiempo real con `fetch`, guardado de preferencias en `localStorage` y cálculo de distancia GPS hacia la tienda. Además, se implementó el carrito de bandeja interactivo «Arma tu surtido» con función de arrastrar y soltar (Drag & Drop), capacidad de 12 prendas, descuento mayorista automático del 15% y un gráfico de resumen en Canvas 2D.
